# Jhony & Sandra – Wedding Invitation & RSVP Web App

An elegant, interactive digital wedding invitation and RSVP web application featuring animated canvas effects, bilingual content, Google Sheets integration for RSVPs, and countdown timers.

## ✨ Features

- **Luxury Aesthetic**: High-end typography, gold borders, and smooth animations.
- **Interactive Background**: Full-screen ambient canvas particle animation.
- **RSVP Form**: Interactive RSVP form connected to Google Apps Script / Google Sheets.
- **Save the Date / Add to Calendar**: Direct calendar event downloads and links.
- **Responsive Design**: Optimized for desktop and mobile viewports.
- **Social Sharing**: Open Graph and Twitter Card metadata for rich link previews (WhatsApp, iMessage, etc.).

## 🚀 Live Demo / GitHub Pages

You can host this directly on **GitHub Pages**:
1. Go to your repository **Settings** > **Pages**.
2. Under **Branch**, select `main` (or `master`) and `/root`.
3. Click **Save**.

## 🛠️ Project Structure

- `index.html` - Main HTML markup and structure.
- `style.css` - Styling, responsive layouts, and animations.
- `app.js` - Dynamic interactions, RSVP handling, and canvas animations.
- `google-apps-script.gs` - Backend script for Google Sheets RSVP collection.
- `favicon.svg` - Website favicon.
- `preview.jpg` - Social sharing preview image.
